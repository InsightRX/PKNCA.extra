# Get the PKNCA options from a spec file, and parse into expected format for `PKNCA::PKNCA.options()`

Get the PKNCA options from a spec file, and parse into expected format
for
[`PKNCA::PKNCA.options()`](https://humanpred.github.io/pknca/reference/PKNCA.options.html)

## Usage

``` r
parse_pknca_opts_from_spec(opts)
```

## Arguments

- opts:

  list of options for PKNCA

## Value

A formatted list of arguments to be passed to
[`PKNCA::PKNCA.options()`](https://humanpred.github.io/pknca/reference/PKNCA.options.html).
